## Subsequent user direction: host-adaptive mixed CLI

After the reconciliation, the user selected native Codex coordinating Claude as the next focus, with **Orca as the first session host and no Orca plugin panel requirement**. Keep independent-of-Orca operation as another route. Shared authority, task/inbox semantics and receipts stay in Team Orchestrator; host adapters supply verified identity, launch and communication methods. Detect the actual host/capabilities rather than relying on an executable name or guessed context. Preserve uncertain effects for reconciliation rather than automatically switching transport and delivering again. Standalone selection/transport still needs implementation and acceptance; host absence or connection loss does not prove an independent session.

[Host-adaptive coordination #179](https://github.com/herman925/925-cc-plugins/issues/179) records the accepted direction and remaining decisions; [mixed teams #48](https://github.com/herman925/925-cc-plugins/issues/48) and [automation interfaces #174](https://github.com/herman925/925-cc-plugins/issues/174) link it. This is a later priority update, not a claim that mixed-CLI support was implemented by the audit above. The native child count after this addition is **52 total, 42 open, 10 closed**.
